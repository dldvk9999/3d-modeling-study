## 클로드 이용해서 3D 파티클 웹 사이트 구현해본 후기

- 일단 클로드에서 Sonnet 으로는 어림도 없음. 따라해보라고 시켰더니 혼자 우주여행 하고있었음.
- 최소 Opus5이상, 노력정도 높음 이상으로 해야 어느정도 비주얼이 나옴.
- 그래서 토큰 진짜 살살 녹음.
- 배경 assets 까진 넣지 않음. 3D 개발에 목적이 있기 때문.
- 그래도 파티클이 많은 것 치곤 렌더링 성능이 떨어지지 않게는 구현 가능.
- 모바일은 어떨지 의문(성능 등등).
- 그래도 신기한점은 Opus는 Sonnet에 비해 원본 사이트 그대로 분석해서 구현해보라고 시키면 해당 사이트의 렌더링 순서를 0.6초 간격으로 프레임을 하나하나찍어가면서 분석함.
- 그건 좋은데 원본만큼 풍성한 느낌의 파티클을 왜 못만드는건진 모르겠음.
- 토큰 남아돌고 관심있을 때 해보면 좋을 듯 함.
